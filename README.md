# THinkING — определение авторства текста

Определяет вероятного автора текста по стилевым признакам, используя нечёткую
логику: стиль каждого автора описывается набором треугольных функций
принадлежности, а анализируемый текст сравнивается с ними по 17 признакам.

Поддерживаются русский и белорусский языки.

## Установка

```bash
pip install -r requirements.txt          # для разработки: requirements-dev.txt
python -c "import nltk; [nltk.download(p) for p in ('punkt','punkt_tab','stopwords')]"
```

Для белорусского языка морфология по умолчанию считается суффиксными
правилами — приблизительно (порядка 85% верных разборов знаменательных частей
речи на ручной выборке). Точный разбор даёт `stanza`:

```bash
pip install stanza   # модель be_hse скачается сама при первом запуске
```

Это тянет за собой torch, около 500 МБ. Без stanza приложение работает и
показывает предупреждение о приблизительном разборе.
Без него белорусские тексты разбираются суффиксной эвристикой, и приложение
явно предупреждает, что результат приблизительный.

## Запуск

```bash
streamlit run app.py            # веб-интерфейс
python main.py                  # полный офлайн-прогон + PNG в output/
python scripts/batch_check.py   # сводка по всем текстам из texts/anonim/
pytest                          # тесты
```

При первом запуске профили авторов обучаются заново и сохраняются в
`authors_profiles*.pkl`; дальше берутся из этого файла. Чтобы переобучить —
удалите файл или нажмите «Переобучить» в боковой панели приложения.

## Структура

| Путь | Назначение |
|---|---|
| `src/feature_extractor.py` | извлечение 17 стилевых признаков |
| `src/profile_builder.py` | треугольные функции принадлежности, нечёткий портрет автора |
| `src/identifier.py` | сравнение текста со всеми портретами |
| `src/visualizer.py` | графики, светлая и тёмная темы |
| `src/report.py` | сводные таблицы признаков (HTML/TXT) |
| `src/io_utils.py` | чтение текстов с перебором кодировок |
| `src/config.py` | авторы, веса, пороги, палитра |
| `main.py` | офлайн-пайплайн: обучение → идентификация → визуализация |
| `app.py` | веб-интерфейс |
| `texts/<автор>/` | обучающие тексты; `texts/anonim/` — тексты для проверки |
| `output/` | результаты офлайн-прогона (в git не попадает) |

## Признаки

Три группы, 17 признаков (`config.FEATURE_LIST`):

- **А. Синтаксис** — медианная длина предложения, дисперсия длин, медианная
  длина абзаца, доли вопросительных / восклицательных предложений, предложений
  с многоточием и с прямой речью.
- **Б. Лексика** — лексическое богатство (MATTR по скользящему окну, устойчив к
  длине текста), доли существительных, глаголов и прилагательных, средняя длина
  слова.
- **В. Пунктуация и служебные слова** — частоты запятых, тире и двоеточий на
  предложение, доли союзов и предлогов.

Вклад каждого признака взвешивается по `config.DEFAULT_WEIGHTS`; итоговая
уверенность — взвешенное среднее степеней принадлежности.

## Настройка

Основное живёт в `src/config.py`:

- `RUSSIAN_AUTHORS_LIST` / `BELARUSIAN_AUTHORS_LIST` — какие папки из `texts/`
  считаются авторами;
- `DEFAULT_WEIGHTS` — веса признаков;
- `CONFIDENCE_THRESHOLD` (0.6) и `HIGH_CONFIDENCE_THRESHOLD` (0.7) — пороги
  вердикта, `MIN_TEXT_LENGTH` (400) — минимальная длина анализируемого текста;
- `MEMBERSHIP_STD_MULTIPLIER`, `SOFTENING` — ширина и мягкость диапазонов;
- `LEVEL_LOG` — `INFO` или `DEBUG`.

## Как добавить автора

1. Создайте `texts/<имя>/` и положите туда `.txt` (7-10 текстов — рабочий минимум).
2. Добавьте `<имя>` в соответствующий список авторов в `src/config.py`.
3. Добавьте отображаемое имя в `AUTHOR_LABELS` и цвет в `AUTHOR_COLORS`.
4. Удалите `authors_profiles*.pkl` и переобучите.
